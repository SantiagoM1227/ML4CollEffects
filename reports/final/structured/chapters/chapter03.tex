\section{Simulation workflow}
\label{sec:simulation_workflow}

Two independently generated simulation datasets are used and are not pooled into a single benchmark. The longitudinal dataset provides one-dimensional density-to-density examples for the Fourier Neural Operator (FNO). The six-dimensional dataset provides paired input--output particle clouds for the CVAE and latent-propagation models. Their numerical errors are task-specific and must not be compared directly.

\subsection{Six-dimensional Xsuite tracking dataset}
\label{subsec:xsuite_tracking_data}

The six-dimensional dataset was generated with Xsuite version~0.48.4, the latest public release available on 1~April~2026 \cite{xsuite_software,iadarola_xsuite_2023}. Xsuite is an open-source Python suite for multiparticle accelerator simulations. In the present workflow, its Xtrack component performs macroparticle transport after the MAD-X lattice description has been imported through \texttt{cpymad}. The complete generation workflow is available in the public \texttt{ML4CollEffects} repository \cite{martinez_ml4colleffects_2026}, serving as the six-dimensional data-generation entry point.

For each sample $s$, a parameter vector $\mu^{(s)}$ and a sampled input beam family define the macroparticle cloud
\begin{equation}
Z_{\mathrm{in}}^{(s)}
=
\left{
\xi_n^{(s)}
\right}*{n=1}^{N_p},
\end{equation}
which is tracked through the selected lattice realization to obtain
\begin{equation}
Z*{\mathrm{out}}^{(s)}
=
\Phi_{\mu^{(s)}}
!\left(
Z_{\mathrm{in}}^{(s)}
\right).
\end{equation}
The resulting supervised dataset is
\begin{equation}
\mathcal{D}*{\mathrm{track}}
=
\left{
\left(
Z*{\mathrm{in}}^{(s)},
\mu^{(s)},
Z_{\mathrm{out}}^{(s)}
\right)
\right}_{s=1}^{2048}.
\label{eq:tracking_dataset_revised}
\end{equation}

The working archive used for the reported models contains 2048 paired trajectories, with $N_p=4096$ macroparticles in each input and output cloud.The fixed data-partition indices are stored in the arrays \texttt{train}, \texttt{val}, and \texttt{test}. The coordinate order used in the archive is
\begin{equation}
\left(
x,
y,
\zeta,
p_x,
p_y,
\delta
\right),
\label{eq:stored_coordinate_order}
\end{equation}
which differs from the canonical plane-grouped notation
$\left(x,p_x,y,p_y,\zeta,\delta\right)$ used in parts of Chapter~\ref{sec:beam_dynamics_data}. Array indices and pairwise-histogram channels follow the ordering in Eq.~\eqref{eq:stored_coordinate_order}; this convention is stated explicitly to avoid ambiguity in the physical interpretation of the stored channels.

The optics input corresponds to the FCC-ee HEB lattice release, obtained from the public FCC-ee HEB optics archive \cite{fcc_heb_lattice_v24_1}. The generation script imports the MAD-X driver, selects the FCC-ee HEB sequence, and converts the selected lattice section into an Xtrack line. The FCC-ee HEB wake and impedance inputs were obtained from the public FCC-ee Booster PyWIT model repository \cite{fcc_ee_booster_pywit_model}. Since both the optics archive and the impedance model remain subject to updates, the archival dataset release will preserve the exact input files used in this work, together with their cryptographic checksums.

For component $\mu_k$, the nominal in-distribution range is defined from the training subset only,
\begin{equation}
    \mathcal{I}_k
    =
    \left[
        \min_{s\in\mathcal{D}_{\mathrm{train}}}\mu_k^{(s)},
        \max_{s\in\mathcal{D}_{\mathrm{train}}}\mu_k^{(s)}
    \right].
    \label{eq:training_parameter_domain}
\end{equation}
No validity claim is made outside $\prod_k\mathcal{I}_k$.



\subsection{PyColleff longitudinal dataset}
\label{subsec:pycolleff_longitudinal_data}

The longitudinal benchmark was generated using the \texttt{pycolleff} module distributed in the LNLS collective effects repository \cite{pycolleff_software}. PyColleff is a Python package for impedance modelling and instability analysis in electron storage rings. In this work, it is used as a controlled operator-learning benchmark rather than as a validated end-to-end model of the FCC-ee HEB. The implemented configuration uses a $3,\mathrm{GeV}$ ring model, a uniform longitudinal grid with $N_{\zeta}=2048$, a resonator contribution with quality factor $Q=10^{4}$, three fixed-point relaxation steps, and an under-relaxation coefficient $\alpha=0.7$. The sampled conditioning variables are the bunch current, chamber radius, and non-evaporable-getter coating thickness. These variables modify the longitudinal response and the resistive-wall and material contributions represented by the benchmark configuration.

For sample $s$, let
\begin{equation}
    \mu^{(s)}
    =
    \left(
        I_b^{(s)},
        R^{(s)},
        t_{\mathrm{NEG}}^{(s)}
    \right).
\end{equation}
The induced voltage is evaluated spectrally as
\begin{equation}
    V_{\mathrm{ind}}(z)
    =
    -\mathcal{F}^{-1}
    \left[
        Z_{\parallel}(\omega;\mu)
        \widehat{\lambda}(\omega)
    \right](z),
    \label{eq:induced_voltage_revised}
\end{equation}
and the total voltage is
\begin{equation}
    V_{\mathrm{tot}}(z)
    =
    V_{\mathrm{RF}}(z)
    +
    V_{\mathrm{ind}}[\lambda](z).
\end{equation}
The truncated fixed-point update is
\begin{equation}
    \lambda^{(k+1)}
    =
    (1-\alpha)\lambda^{(k)}
    +
    \alpha\mathcal{T}_{\mu}
    \!\left(\lambda^{(k)}\right),
    \label{eq:pycolleff_relaxation_revised}
\end{equation}
with $K=3$ iterations and $\lambda_{\mathrm{out}}=\lambda^{(K)}$. The resulting data are
\begin{equation}
    \mathcal{D}_{\lambda}
    =
    \left\{
        \left(
            \lambda_{\mathrm{in}}^{(s)},
            \mu^{(s)},
            \lambda_{\mathrm{out}}^{(s)}
        \right)
    \right\}_{s=1}^{2048}.
\end{equation}
The released configuration must state the numerical ranges and units of every component of $\mu$, the RF settings, impedance components, material model, boundary conventions, and PyColleff version. This prevents the FNO result from being mistaken for a surrogate of an unspecified or different impedance model.


\subsection{Data representation and physical quantities}
\label{subsec:data_representation_physical_quantities}

\subsubsection{Empirical measures and reduced profiles}

A cloud defines the empirical probability measure
\begin{equation}
    \rho^{N_p}
    =
    \frac{1}{N_p}
    \sum_{n=1}^{N_p}
    \delta_{\xi_n}.
\end{equation}
For the longitudinal task, this measure is projected onto the uniform grid $\{\zeta_j\}_{j=1}^{N_{\zeta}}$ to form
\begin{equation}
    \lambda^h
    =
    \left(
        \lambda(\zeta_1),\ldots,
        \lambda(\zeta_{N_{\zeta}})
    \right)
    \in
    \mathbb{R}^{N_{\zeta}}.
\end{equation}
The profile is normalized to unit integrated mass before being supplied to the FNO.

\subsubsection{Fifteen pairwise phase-space projections}

A direct $64^6$ discretization of the full six-dimensional density is infeasible. The tracking state is therefore represented by all fifteen pairwise two-dimensional histograms,
\begin{equation}
    \mathcal{P}
    =
    \left\{(i,j):1\leq i<j\leq6\right\},
    \qquad
    \mathcal{H}(\rho)
    =
    \left\{H_{ij}\right\}_{(i,j)\in\mathcal{P}}
    \in
    \mathbb{R}^{15\times64\times64}.
    \label{eq:histogram_representation_revised}
\end{equation}
For sample $s$, coordinate $i$ is histogrammed over the sample-adaptive interval
\begin{equation}
    \left[
        m_i^{(s)}-5\sigma_i^{(s)},
        m_i^{(s)}+5\sigma_i^{(s)}
    \right],
    \label{eq:sample_adaptive_histogram_range}
\end{equation}
where $m_i$ and $\sigma_i$ are the empirical centroid and coordinate-wise RMS spread defined in Eq.~\eqref{eq:empirical_centroid_rms_definition}. Every pairwise channel is converted to a probability-mass array,
\begin{equation}
    \sum_{a=1}^{64}
    \sum_{b=1}^{64}
    H_{ij}^{(s)}[a,b]
    =1.
    \label{eq:histogram_mass_normalization}
\end{equation}
Thus, the CVAE histogram branch models normalized projected shape. The six centroids and six RMS spreads are retained as a separate 12-component physical vector and provide the location and coordinate scale omitted by independent channel normalization. When a physical probability density is required, the normalized mass is divided by the physical bin area,
\begin{equation}
    \rho_{ij}^{(s)}[a,b]
    =
    \frac{H_{ij}^{(s)}[a,b]}
    {\Delta\xi_{i,a}^{(s)}\Delta\xi_{j,b}^{(s)}}.
    \label{eq:mass_to_physical_density}
\end{equation}

The word \emph{beam size} is therefore not used for all twelve auxiliary quantities. The transverse position spreads $\sigma_x$ and $\sigma_y$ may be related to conventional optical beam sizes under the assumptions stated in Section~\ref{subsubsec:beam_descriptors_definition}; the remaining entries are coordinate-wise RMS spreads of $p_x$, $p_y$, $\zeta$, and $\delta$. The RMS definition remains meaningful for non-Gaussian distributions but is not a complete shape descriptor. Non-Gaussian information is carried by the histograms, while explicit quantiles are left to future work.

Pairwise marginals do not uniquely determine a six-dimensional joint density and predicted channels need not be mutually consistent. For coordinate $i$, let $h_i^{(ij)}$ be the one-dimensional marginal obtained by summing $H_{ij}$ over coordinate $j$. A shared-marginal consistency diagnostic is
\begin{equation}
    \mathcal{E}_{\mathrm{cons}}
    =
    \frac{1}{6}
    \sum_{i=1}^{6}
    \frac{1}{|\mathcal{C}_i|}
    \sum_{(ij),(ik)\in\mathcal{C}_i}
    \left\|h_i^{(ij)}-h_i^{(ik)}\right\|_1,
    \label{eq:marginal_consistency_metric}
\end{equation}
where $\mathcal{C}_i$ contains histogram channels sharing coordinate $i$.

\subsection{Data and code availability}
\label{subsec:data_code_availability}

At the time of writing, the curated datasets are being prepared for public deposition in Zenodo. The record will contain the immutable train--validation--test indices, generation and preprocessing scripts, configuration files, software environment, lattice source and checksum, parameter ranges and units, and a machine-readable manifest of all array shapes. The record will be tagged with both FCC and TwinRISE. Its DOI will be inserted in the archival thesis version once the deposit has been approved and minted.

The training, evaluation, figure-generation, and data-generation code developed for this work is publicly available under the MIT licence in the ML4CollEffects github repository \cite{martinez_ml4colleffects_2026}. The six-dimensional datasets were generated using the entry-point script included in the same repository. Since the codebase remains under active development, the final archival record will reference and preserve the exact Git release or commit corresponding to the results reported in this thesis, rather than relying on the evolving \texttt{main} branch. Until the curated Zenodo record is available, the numerical arrays may be requested from the author, subject to the applicable FCC collaboration and institutional release procedures.
